# 📌 MVP - Nexa Chemical

## 🎯 Objetivo do MVP
> Disponibilizar a terceira versão operacional do dashboard, possibilitando a visualização dos principais indicadores essenciais.
- **Problema solucionado:** Falta de uma visão integrada do crescimento moderado e consistente em São José dos Campos, além de identificar os setores que mais contrataram em determinado período, bem como a exportação de dados em Excel, PDF ou Arquivo MVP.
- **Hipótese:** Dashboard simples que já permite que os gestores identifiquem padrões relevantes.
- **Valor Entregue:** Visualização unificada com dados organizados e tratados.

---

## 📝 Descrição da Solução
> Aprimoramento da base inicial com a implementação de variados componentes da interface.  
- **Funcionalidades incluídas:**  
  - Estrutura inicial do painel
  - Terceira visualização dos dados
  - Integração preliminar com as bases utilizadas.
- **Limitações:** Limitação no conhecimento de Power Bi para determinadas análises. 
- **Escopo reduzido:** Realização do tratamento de dados e construção do terceiro protótipo do dashboard.

## 📊 Critérios de Aceitação

- O MVP deve permitir que o usuário filtre os setores com crescimento moderado para reconhecer tendências no mercado, além de visualizar o setor que mais empregou indivíduos em determinado período, bem como o acesso dos arquivos via: Excel, PDF ou Arquivo MVP.
- O sistema precisa registrar o uso de filtros, consultas, comparações e visualização de gráficos, garantindo que os dados sejam provenientes de fontes oficiais e confiáveis.
- Métricas coletadas: tempo de resposta, uso de filtros, frequência de comparações, visualizações e exportações, e tempo médio de uso.

---

## 📈 Métricas de Validação

* O MVP permite que o usuário identifique os setores que apresejtam crescimento moderado para reconhecer tendências de mercado, além de permitir a visualização do setor que mais gerou empregos em um determinado período específico, bem como possibilitar o acesso aos arquivos nos formatos: Excel, PDF e Arquivo MVP..
